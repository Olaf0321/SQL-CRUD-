# SQLite CRUD Web アプリケーション

## 概要

このアプリケーションは、SQLiteを使用したレコード管理のためのWebアプリケーションです。SQLiteのテーブル一覧を表示し、各テーブルに登録されているレコードを表示、追加、更新、削除ができる機能を提供します。

さらに、簡単なログイン機能を実装し、一定時間後にセッションが切れるようになっています。また、検索やソート機能、リスト選択機能、入力対象の絞り込み機能も備えています。

## 機能概要

- **テーブル表示**: SQLiteのテーブル一覧を表示。
- **レコード管理**: レコードの表示、追加、更新、削除が可能。
- **ログイン機能**: 簡単なログイン機能、セッションタイムアウト対応。
- **検索・ソート**: テーブル内のデータに対して検索およびソートが可能。
- **リスト選択機能**: Excelのリスト選択のような機能で、カラムを選択して表示可能。
- **絞り込み機能**: 外部キー(FK)を使った絞り込み、親子関係のレコード表示。
  
## 開発環境

### 必要なツール

- **Node.js**: 推奨バージョン: v18.x
- **Python**: 推奨バージョン: v3.9以上
- **Git**: インストール済み
- **SQLite3**: 付属のDBファイルを使用

### 動作環境

- **Windows 10/11** 環境
- **SQLite3** に依存し、ローカル環境で動作します。
