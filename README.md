# SQLite レコードビューア & エディタ

本アプリケーションは、SQLite データベースファイル（例：Northwind_small.sqlite）を読み込み、ブラウザ上で簡単にテーブルのレコードを閲覧・編集できるツールです。  
SQL の知識がない方でも直感的に操作可能で、データの追加・編集・削除を手軽に行うことができます。

---

## 特徴

### 🔸 テーブル一覧の表示
- SQLite ファイル内に存在する全テーブルをサイドバー等に一覧表示。
- テーブル名をクリックすると、そのテーブルのレコード一覧を表示します。

### 🔸 レコードの CRUD 操作
- レコードの **追加／更新／削除** に対応。
- 入力フォームは動的に生成され、各カラムに対応した入力欄を表示。
- 新規レコードは簡易的な入力フォームから追加可能。

### 🔸 ソート・検索機能
- 列のヘッダーをクリックすることで **昇順／降順ソート**。
- テーブル上部に検索ボックスを設置し、 **キーワードによる絞り込み検索** が可能。

### 🔸 リスト選択機能（Excelのドロップダウン風）
- 設定ファイル（JSON 等）で指定したカラムに対し、プルダウン形式で選択肢を提供。
- ユーザーは自由入力ではなく、定義済リストから選択するだけで操作可能。

### 🔸 入力対象の絞り込み機能（外部キー対応）
- 外部キー（FK）が設定されているカラムについて、上位テーブルの ID による **連動絞り込み表示** に対応。
- 上位IDでフィルタリングした状態でレコードを追加した場合、自動的にそのIDがマッピングされます。
- 「全表示」と「絞り込み表示」を切り替えるモードも提供予定です。

---

## 非対応の機能（このアプリでは扱いません）

- テーブル・カラムの新規作成や削除
- SQLクエリの直接実行機能
- ER図の生成やインデックス操作などの高度な機能

※ 目的は「データの閲覧と編集」に特化しており、ITスキルの高くない方でも扱いやすい構成を重視しています。
