# SQLite CRUD Web アプリケーション

## 概要

このアプリケーションは、SQLiteを使用したシンプルなレコード管理用Webアプリケーションです。SQLiteのテーブル一覧を表示し、各テーブルに登録されているレコードを表示、追加、更新、削除ができる機能を提供します。また、簡単なログイン機能を実装し、一定時間後にセッションが切れるようにしています。

主要な機能としては、検索、ソート、リスト選択、入力対象の絞り込み機能を備えています。外部キー（FK）を使用した親子関係のレコード表示機能も含まれています。

## 特徴・機能

- **テーブル表示**: SQLiteのテーブル一覧を表示。
- **レコード管理**: レコードの表示、追加、更新、削除が可能。
- **ログイン機能**: セッション管理が可能、一定時間後に自動でセッションが切れる。
- **検索・ソート**: テーブル内のデータを検索およびソートが可能。
- **リスト選択機能**: Excelのリスト選択のようなUIで、カラム選択が可能。
- **絞り込み機能**: 外部キー(FK)による親子関係の絞り込み表示が可能、新規レコード追加時に親IDが自動でマッピング。
